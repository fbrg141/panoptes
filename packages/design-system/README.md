# @panoptes/design-system

Tokens, fonts, logos, app icons and React components for Panoptes. The brand
and usage guide is [GUIDE.md](GUIDE.md); read it before designing a screen.

## Use

```ts
import "@panoptes/design-system/styles.css"; // fonts + tokens + component styles
import { Button, LoopMark, StatusPill } from "@panoptes/design-system";
```

Set `data-theme="dark"` (the default) or `data-theme="light"` on `<html>`.
Every token is a CSS variable (`var(--surface)`, `var(--ink-muted)`, ...), and
each type style is a class (`text-body`, `text-caption`, `text-code`).

## Contents

| Path | What |
|---|---|
| `tokens/tokens.json` | Source of truth for every token |
| `tokens/tokens.css`, `tokens/tokens.dtcg.json` | Generated from `tokens.json` (CSS variables; W3C format) |
| `src/index.js`, `src/index.d.ts`, `src/components.css` | Components, generated by the design tool |
| `fonts/` | IBM Plex Sans, IBM Plex Mono, Gloock (woff2) |
| `assets/logos/` | The mark and lockup, one ink each |
| `assets/app-icons/` | The eight 1024px app icons; `pupil-on-bone` is the default |

## Changing it

The design system is maintained in its design tool, which exports
`tokens/`, `src/` and the assets. Change it there and re-export into this
folder; don't hand-edit generated files, or the next export will overwrite
the change.
